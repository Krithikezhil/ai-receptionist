# @ai-receptionist/shared

Shared TypeScript types and constants used by `apps/web` and `apps/api`.

## M1 status

Contains only foundational types (`TenantId`, `TenantScoped`, `ServiceHealth`) that
document the multi-tenant data shape described in [ARCHITECTURE.md](../../ARCHITECTURE.md).
No real domain models (organizations, users, calls, leads, etc.) exist yet.
